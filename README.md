# HTB-CWES-Writeups-2026
HTB CWES Writeups 2026 and Tips


## Preparation course
A crucial point: to be even eligible for the exam, you must complete 100% of the course material and solve the skills assessment at the end of each module. Without this, the exam remains locked.

The path consists of about 20 modules, ranging from easy to medium difficulty. All the material is text-based — there are no videos or presentations. I ran into some difficulties with a few tasks, but the hints found online and in the official HTB Discord channel were lifesavers.

## The Exam
One big plus I should mention right away — there’s no need to book anything in advance. You can jump onto the platform and hit the start button whenever you’re ready. You get 7 days in total, which includes both lab access and writing the report. No extra time is given for the report, so keep that in mind.

In the exam, you’ll face several applications where you need to collect user and root flags. Usually, getting a flag requires exploiting one vulnerability or a chain of two. Often, you’ll need to do something “extra” or use a certain “trick” that you have to figure out on your own. However, there were some straighforward flags, just like the skills assessments at the end of the modules.

Overall, the difficulty was on par with the skills assessments, maybe slightly harder in some spots. I collected all the flags by the 4th day and then started working on the report.

## My Tips
Take Detailed Notes. This is non-negotiable. The training modules often contain small details or specific code snippets that can serve as direct hints during the exam. Document everything so you can quickly find it using search.


Run through Skills Assessments twice. Before you start the exam, go back and solve the final module tasks one more time. I also recommend re-reading the learning modules to ensure you can navigate the material quickly. During the exam, you will find yourself going back to the course text looking for ideas.

Extra Practice is Key. As I mentioned, the modules alone might not be enough. Experience solving machines on the main HTB platform is invaluable. Some suggest the Bug Bounty Hunter track, and while I haven’t completed it myself, it seems like a solid choice for manual exploitation practice.

Filter Your Recommendations. For instance, I completed parts of the CPTS path by IppSec, but for this specific exam, it was almost useless. You need machines that require manual web exploitation, not just finding a public exploit for an outdated application.
